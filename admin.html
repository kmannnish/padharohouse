Adding a team member
  1. Firebase console → Authentication → Users → Add user (email + password).
  2. Copy the new user's UID.
  3. Firestore → collection users → document ID = that UID → fields role (super_admin or manager), name, email.

Roles are deliberately not editable from this page — if the browser could change roles, anyone signed in could promote themselves. The security rules reject any client write to users.

super_admin

Everything: site mode, tariff, packages, financials, team, bookings, calendar, WhatsApp.

manager

Operations only: bookings, calendar availability and the WhatsApp queue.
