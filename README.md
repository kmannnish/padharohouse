# Padharo House

Website for **Padharo House** — a luxury boutique homestay in Amer, Jaipur, right opposite the Amber (Amer) Fort. *Where heritage meets hospitality.*

**Live site:** https://padharohouse.in · **Instagram:** [@padharo_house](https://www.instagram.com/padharo_house)

## What's here
| Path | Purpose |
|------|---------|
| `index.html` + `assets/` | **Phase 1 — Opening Soon page** (currently live at the domain root) |
| `prototype/` | Full-site design prototype (Home, Booking, Journal, Admin) — reference only, not indexed by search engines |

## Phases
- ✅ **Phase 1** — Opening Soon landing page
- ⏳ **Phase 2** — Full booking website (rooms, live booking engine, payments, admin dashboard)

## Hosting & deploys
Hosted on **Cloudflare Pages**, connected to this GitHub repo:
- Every push/merge to **`main`** deploys automatically to **production** (the live site).
- Every **pull request** gets its own **preview URL** to review changes before they go live.

No build step — this is a static site (plain HTML/CSS). Build output directory: `/` (repository root).
